# Moekyawaung-portfolio-website-05 🚀

This project is a personal portfolio website built with React and Vite, styled using Tailwind CSS. It showcases the expertise of Moe Kyaw Aung as a Senior Android Developer and offers a comprehensive career roadmap for aspiring and mid-level Android engineers.

## 🌟 Features

- **Modern Tech Stack:** Built with React, Vite, and TypeScript.
- **Responsive Design:** Utilizes Tailwind CSS for a sleek and adaptive user interface.
- **Animated Experience:** Integrates `framer-motion` for smooth and engaging animations.
- **Interactive Components:** Features custom components for navigation, hero sections, features, pricing, testimonials, FAQs, and more.
- **Clear Career Roadmap:** Details a 12-week roadmap covering modern Android development, architecture, performance, system design, and interview preparation.
- **Testimonials & Social Proof:** Displays endorsements from engineers at top tech companies and lists companies where mentored engineers work.
- **Contact & Call to Action:** Provides clear calls to action for obtaining the roadmap and booking consultation calls.

## 🛠️ Tech Stack

- **Frontend:** React, Vite, TypeScript
- **Styling:** Tailwind CSS
- **Animations:** `framer-motion`
- **UI Icons:** `lucide-react`
- **Utilities:** `clsx`, `tailwind-merge`

## 🚀 Installation

To get started with this project locally:

1.  **Clone the repository:**
    ```bash
    git clone https://github.com/Dev-moe-kyawaung/Moekyawaung-portfolio-website-05.git
    cd Moekyawaung-portfolio-website-05
    ```

2.  **Install dependencies:**
    ```bash
    npm install
    # or
    yarn install
    ```

3.  **Run the development server:**
    ```bash
    npm run dev
    # or
    yarn dev
    ```

This will start the development server, and you can view the website at `http://localhost:5173` (or the port specified by Vite).
